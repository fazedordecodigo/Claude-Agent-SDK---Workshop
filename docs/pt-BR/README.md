# Claude Agent SDK — Workshop

Versao em portugues brasileiro.

English default: [../../README.md](../../README.md)

Projeto de estudo em PT-BR sobre o workshop do Claude Agent SDK, realizado no AI Engineer Code Summit e organizado a partir da transcricao original em `../transcription.txt`.

A Anthropic publicou um curso completo de 2 horas sobre a construcao de agentes Claude, apresentado por um engenheiro que constroi o Claude Code. Este material reestrutura esse conteudo como artigo didatico, dividido em capitulos navegaveis, com exemplos praticos, explicacoes aprofundadas e referencias complementares.

## Topicos cobertos

- diferenca entre agentes e workflows;
- uso de Bash e filesystem como primitivas agenticas;
- geracao de codigo para tarefas que nao sao codigo;
- seguranca, permissoes, sandbox e guardrails;
- design de loops com contexto, acao e verificacao;
- uso de skills, hooks e subagentes;
- exemplos com e-mail, planilhas e Pokemon/PokeAPI;
- caminhos de prototipo para producao com o Claude Agent SDK.
